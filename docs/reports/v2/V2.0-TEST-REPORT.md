## 7. 遗留与说明

1. Redirect 链中 RouteLaunch 元数据反映**最终目标页**（如 /mock/second）；原始 path 未作为 extra 透传（由日志/页面横幅说明承载），需要时可后续加。
2. Mock 演示映射仅 `/second → /mock/second`（演示最小集）；MockInterceptor 本身通用。
3. 动态增删拦截器、@Interceptor 注解级拦截不在 V2.0（方案 §1 明示），留待后续里程碑评估。
4. 拦截器日志受 isDebug 控制；拦截**行为**与 onLost 同属「行为开关」，不受 isDebug 影响（S10-5 固化）。
