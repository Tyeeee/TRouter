# TRouter V5.0 动态路由 + 路由图谱 · 测试报告

> **先说人话**
> 这份报告验证的是 V5.0 新做的两件事：一是"运行时才注册页面"（页面编译时还不存在，也能先登记一条路径再用它打开），二是"路由图谱"（把当前所有路径和它们指向的页面看成一张图，能看到有几个节点、几条边）。
> 主要看三件事：注册了能不能打开、注销后是不是又变成"没这条路径"、重复注册会不会被拒绝而不是悄悄覆盖。
> 结论：通过——本版 5 个用例连跑两遍全绿。按约定，这一版**只测 V5 新功能**，V1–V4 的历史用例留到最后的统一回测一起跑。

先认几个报告里反复出现的说法：

- **V1.0 / V2.0 …… / V5.0**：本项目的里程碑版本号，每个版本加一层能力（V1 基础跳转、V2 拦截器、V3 多模块、V4 跨进程、V5 动态路由 + 图谱）。
- **C1…C5 / O1 / T1**：验收清单（DoD，即"做到哪些事才算完"）里的编号——C 是功能验收项，O 是可观测性（日志证据），T 是测试方式。
- **O1–O5**：`docs/V5.0-动态路由与图谱方案.md` 这份方案里的条目编号。
- **L2/L3**：`docs/版本回顾与缺口核查.md` 那份缺口清单（L1–L11）里的编号，L2＝运行时动态增删拦截器的 API，L3＝`@Interceptor` 注解级静态拦截。
- **S13/S14**：主页上的场景编号（S13＝注册/注销动态路由，S14＝打开动态注册的页面）。
- **KSP**＝编译期自动生成代码的工具；**插桩测试**＝跑在真机/模拟器上的自动化测试。

> 状态：**完成待统一回测**。V5.0 方案（`docs/V5.0-动态路由与图谱方案.md`）的 O1–O5 按推荐默认实施；

1. 按测试协议：本报告**没有**跑 V1–V4 历史的 26 例（各版本当时已经绿了）；统一回测最后执行（预计 26 + 5 + 回测专项）。

3. 动态注册不校验目标类是否存在（保持惰性，和静态注册一致）：类不存在时 navigate 走既有的降级（NotFound+onLost）。
