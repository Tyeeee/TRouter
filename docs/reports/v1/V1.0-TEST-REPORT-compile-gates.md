## 2. Step 2 常量解析探针结论（R-2 风险解除）

KSP2（Analysis API）可将「引用二进制依赖 `const val`」的注解参数**折叠为字面值**：

```
w: [ksp] PROBE[@Route] com.demo.trouter.MainActivity   path raw=/main   type=String  literalBySource=false
w: [ksp] PROBE[@Route] com.demo.trouter.SecondActivity path raw=/second type=String  literalBySource=false
```

→ RouterContract 常量引用方案成立：path 值参与冲突检测与生成；字面量与否由处理器读源文件判定。
→ 无需执行 R-2 降级规则（Warning + `__UNRESOLVED_CONSTANT__` + 跳过生成），该规则保留为异常兜底。
（探针日志随后已从处理器移除。）

## 4. C3 生成物核对

`GroupLoader_default.kt`（group=default，含 2 条路由）：

- path = `/main` / `/second`：**常量折叠后的字面值**（源文件引用 RouterContract，故无 Warning）；
- targetClassName = 类名字符串（`com.demo.trouter.MainActivity` / `com.demo.trouter.SecondActivity`）；
- 生成代码**不含 `::class` 引用、不含 `Class.forName`** → `TRouter.init/install` 阶段不会加载任何页面类；
  页面类只在 `navigate()` 时经 `Class.forName` 真正加载（满足 C3「init 后不加载具体路由类」与惰性语义）。

`TRouterGroupRegistry.kt`：object 实现 `GroupLoaderRegistry`，聚合所有 `GroupLoader_*`，
供 `TRouter.install(...)`（宿主 Application 与测试 `BaseTRouterTest.provideRegistry()` 注入）装配。
