## 1. 目标与范围（V5.0 验收清单草案）

| # | 类别 | 验收项 |
|---|---|---|
| C1 | 动态注册 | `TRouter` 提供运行时注册/注销路由 API（不依赖 KSP 生成物），注册后 navigate 可用、注销后回 NotFound |
| C2 | 冲突语义 | 动态注册与既有 path（静态或动态）冲突 → **拒绝 + 告警日志**（要求先 unregister，Fail-Fast 显式语义），不静默覆盖 |
| C3 | 同表共存 | 动态与静态路由在同一 RouteTable 共存：拦截器链、NotFound/onLost、惰性加载、快照/图谱全部自动生效 |
| C4 | 图谱 | core 提供路由图谱模型（节点=目标类，边=path），可从当前路由表实时导出；含静态+动态 |
| C5 | 可观测 | 注册/注销输出结构化日志节点；图谱内容进 `registeredRoutes()` 体系（快照/演示页可见） |
| T1 | 测试（本版） | 只测 V5：动态注册/注销/冲突/图谱的契约 + UI 用例；不跑历史 26 例（统一回测最后做） |
| O1 | 可观测 | 图谱可被 demo 页/测试以确定性文本读取（含节点数/边数/样例），证明动态与静态同图 |

**V5.0 明确不含**：动态路由持久化/热更下发、路由表跨进程同步（remote 进程各自独立表，属跨进程课题边界）、拦截器动态增删（backlog L2）、@Interceptor（L3）、图谱可视化 SDK（仅 demo 文本/文件导出级）、统一回测（最后执行）。

## 2. API 草案（`trouter-core` api 包；RouteMeta/TRouterResult 零改动）

```kotlin
object TRouter {
    /**
     * 运行时注册路由（V5.0）。与静态生成路由同表共存。
     * @return true 注册成功；false 失败（未初始化 / 重复 path 冲突）
     */
    fun registerRoute(meta: RouteMeta): Boolean

    /** 运行时注销路由（V5.0）：静态与动态均可注销。@return true 确有移除。 */
    fun unregisterRoute(path: String): Boolean

    /** 路由图谱（V5.0）：由当前路由表实时导出的只读模型。 */
    fun routeGraph(): RouteGraph
}

/** 图谱只读模型（api，无 null）：节点=目标类全名，边=path（含来源 kind/group）。 */
data class RouteGraph(
    val nodes: List<String>,            // 目标类全名（含动态注册的类）
    val edges: List<RouteGraphEdge>,    // 每条注册路由一条边
) {
    data class RouteGraphEdge(val path: String, val group: String, val kind: RouteTargetKind, val toClass: String)
}
```

- 实现底座：复用内部 `RouteTable`（现有 register 已幂等），新增公开包装 + **冲突检测**（重复 path：registerRoute 拒绝并输出 `[route][register][conflict]`，`unregisterRoute` 先删后注为推荐用法）。
- `RouteMeta` 复用意味着：动态目标同样只存**类名字符串**（惰性），可注册任意已存在的 Activity/Fragment 类（如未标注 @Route 的页面）。
- 图谱节点按目标类聚合、边按注册路由；保证确定性顺序（按注册次序/快照次序），测试可断言。
- 初始化/重置语义：未 init → register/unregister 返回 false + 日志；`resetForTest()` 清空（含动态）。

## 5. 风险登记

| # | 风险 | 缓解 |
|---|---|---|
| R-1 | 动态注册破坏既有"KSP 静态表"叙事/歧义（动态 vs 静态目标类不存在） | registerRoute 不校验类存在（保持惰性，与静态一致）；不存在则导航时 NotFound+onLost（既有降级） |
| R-2 | 新增 public API 影响历史测试 | 不改 RouteMeta/TRouterResult/既有 navigate 语义；冲突仅新注册路径生效；历史回测统一最后跑 |
| R-3 | 图谱顺序不稳定 | 按路由表插入序导出（LinkedHashMap 语义），测试断言集合+数量为主、序为辅 |
